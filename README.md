Учебное веб-приложение для распределения и контроля сельскохозяйственных работ. Руководитель вручную назначает задачи, а сотрудники отмечают выполнение своей части работы.

## Возможности MVP

- Вход по логину и паролю, роли руководителя и работника.
- Создание задач с описанием, участком, типом работы и сроками.
- Назначение одного или нескольких исполнителей.
- Отдельный статус выполнения для каждого работника.
- Контроль общего статуса, прогресса группы и просроченных задач.
- Комментарии о результатах, история изменений и простая сводка.

## Работа с задачами

Руководитель создаёт задачу и выбирает исполнителей. Каждый работник переводит своё назначение из «Не начата» в «В работе», затем в «Завершена».

По модели, описанной в ТЗ, после завершения всех назначений задача получает статус «Ожидает подтверждения». Руководитель подтверждает результат и переводит её в «Выполнена». Также предусмотрена отмена задачи. Просрочка отображается отдельным признаком.

## Технологии и архитектура

| Компонент | Решение |
| --- | --- |
| Бэкенд | Go (Golang), единое серверное приложение |
| Фронтенд | Предлагаются HTML, CSS и JavaScript без обязательного фреймворка |
| Обмен данными | REST API, JSON, HTTPS |
| База данных | Реляционная; конкретная СУБД пока не выбрана |

Фронтенд отвечает за страницы, формы и отображение данных. Бэкенд проверяет права доступа, выполняет бизнес-логику и сохраняет данные. Серверный код разделяется на обработчики запросов, бизнес-логику и слой доступа к БД.

Основные экраны: вход, задачи руководителя, мои задачи работника, карточка задачи, форма создания и редактирования. Для демонстрации планируется один сервер Go и одна база данных.

## Границы проекта

MVP ориентирован на простое управление задачами. Автоматическое назначение, погодные сервисы, датчики, управление поливом, сложная аналитика и отдельное мобильное приложение в него не входят.
